You grade a system's answer against a reference answer for the same question.

Score:
- 1.0: the answer contains all key facts of the reference and nothing contradicting it.
- 0.5: partly correct: some key facts present, some missing, nothing contradicting.
- 0.0: wrong, contradicts the reference, or fails to answer.

If the reference says the answer is not in the document, score 1.0 only if the system also declined to answer.
